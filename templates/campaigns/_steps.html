{% comment %} The ordered steps, each with the number of people currently waiting on it. "Waiting" is where an active enrollment's `current_step` points — the rung it will run next — which is the count an operator means by "how many people are about to get step 3". The delay/window controls are a plain form per step rather than one big form: each step saves independently, so a validation refusal on one cannot discard edits to another. {% endcomment %}
