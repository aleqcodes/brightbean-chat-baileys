Autenticação

Toda solicitação deve incluir uma chave de API criada em Configurações → Organização → Chaves de API:

Authorization: Bearer {{ token_prefix }}…

Cada chave é válida para um único espaço de trabalho; não é possível fazer chamadas entre espaços nem ampliar o escopo após a criação. Solicitações sem uma chave válida recebem 401. Fora do ambiente de desenvolvimento, chaves enviadas por HTTP simples são recusadas, pois já teriam sido registradas por cada intermediário.

Limites de requisições

{{ rate_limit }} solicitações por segundo por chave. Ao ultrapassar o limite, a resposta é 429 com o cabeçalho Retry-After; o intervalo é de um segundo, portanto o cabeçalho informa o tempo exato de espera. As chaves não competem entre si.

Solicitações

Envie JSON e receba JSON. O corpo tem limite de {{ max_body_bytes }} bytes, e chaves desconhecidas são rejeitadas em vez de ignoradas. Um erro de digitação no nome de um campo retorna 422, sem descartar o valor silenciosamente.

Paginação

Todos os endpoints de lista retornam o mesmo formato:

{
  "data": [ … ],
  "has_more": true,
  "next_cursor": "eyJvIjo1MH0"
}

Informe ?limit= (1–{{ max_limit }}, padrão {{ default_limit }}) e ?cursor=. O cursor é opaco: devolva next_cursor sem modificá-lo e nunca o construa manualmente. Continue a paginação enquanto has_more for verdadeiro. Não há total, pois contar os contatos de um espaço de trabalho custa mais do que retornar a página.

Webhooks de saída

Configure endpoints por espaço de trabalho em Configurações → Organização → Webhooks. Cada entrega é uma solicitação POST com:

Como verificar uma entrega

A assinatura consiste em v1= seguido do HMAC-SHA256 hexadecimal, calculado sobre o timestamp, um ponto literal e o corpo bruto da solicitação, nessa ordem, usando os bytes recebidos antes de qualquer análise do JSON. 

import hashlib, hmac, time

def verify(secret, headers, raw_body, tolerance={{ timestamp_tolerance }}):
    timestamp = headers["{{ timestamp_header }}"]
    presented = headers["{{ signature_header }}"]
    if abs(time.time() - int(timestamp)) > tolerance:
        return False
    signed = timestamp.encode() + b"." + raw_body
    expected = "v1=" + hmac.new(secret.encode(), signed, hashlib.sha256).hexdigest()
    return hmac.compare_digest(expected, presented)
Compare em tempo constante, verifique o timestamp e use {{ delivery_header }} como chave de deduplicação. A entrega é feita pelo menos uma vez. Responda com 2xx para confirmar. Entregas com falha são repetidas com intervalos progressivos; após {{ failure_limit }} falhas consecutivas, o endpoint é desativado e os administradores do espaço de trabalho são notificados.
